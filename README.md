# 고스트다이빙코리아 프로젝트 관리 · v23

기존 배포 폴더의 index.html, app.js를 교체하고 logo.png는 그대로 유지하세요.
같은 사이트 주소·기기·브라우저에서 기존 저장값을 이어서 사용합니다.

## 정산 화면
1. 발생 비용 입력: 기존 비용 항목·총액·배분 기준 유지. 11개 비용 항목을 한 줄에서 입력. 배분 설정과 개인별 상세표는 접어서 표시.
2. 개인 선결제: 기존 기납부 금액을 그대로 사용. 결제자별 선구매 내역 입력 추가.
3. 개인별 정산: 배정 비용 - 개인 지원금 - 선결제액. 기존 1,000원 단위 올림 유지. 양수는 추가 납부, 음수는 환급 예정.
4. 프로젝트 최종 요약: 총 발생 비용 - 프로젝트 지원금. 개인 지원금·선결제를 중복 차감하지 않음.

멤버 리조트 총액은 개인에게 자동 배분하지 않습니다. 선결제한 구매비는 발생 비용에 한 번 포함해야 합니다. 선구매 내역은 설명이며 별도 비용을 자동 추가하지 않습니다.
프로젝트 지원금은 전체 요약에만 적용되며 멤버/객원 대상 정산서에 임의 배분하지 않습니다.
PDF 저장 버튼을 제거했습니다. 기존 PNG 저장은 유지합니다.
현재 작업·보관함·JSON 백업에 새 입력값도 저장됩니다. 연간 지원비에는 지원 체크 항목, 추가 프로젝트 지원금, 개인 지원금이 포함됩니다.
배포 전 기존 사이트의 프로젝트 보관함에서 전체 데이터 백업(JSON)을 보관하세요.

정산 PNG: 성명이 있는 행만 출력하고, 금액이 없는 비용 열을 제외합니다. 개인부담·올림차액·빈 비고 열을 제외하고 최종 납부를 강조합니다. 환급은 음수 대신 환급으로 표시합니다. 실제 내용에 맞춘 크기로 한 장을 저장합니다. 계좌 아래 안내문은 출력하지 않습니다.

비용 항목별 고다 지원/비지원을 선택합니다. 기존 항목은 비지원으로 시작하여 이전 금액을 유지합니다. 지원 체크한 항목은 개인 부담에서 제외하고 고다 지원비 합계로 집계합니다. 비지원 항목은 기존 정산 합계에 반영합니다. 다이빙 항목 지원 선택은 멤버·객원 다이빙비 전체에 적용합니다. 기존 멤버 리조트 총액의 개인 미배분 규칙은 유지됩니다. 추가 프로젝트 지원금은 항목 지원과 별도이며, 기존 값을 유지하므로 동일 지원금이 중복 입력되지 않도록 확인하세요.

## v23 카드결제·부가세
항목별 부가세 +10% 체크는 다이빙솔루션 카드결제를 뜻합니다. 체크 시 입력한 공급가에 항목별 10%를 원 단위 반올림해 가산합니다. 고다 지원 선택은 비활성화되며, 해당 비용은 고다/멤버/객원 비용에서 제외하여 카드결제 비용에만 집계합니다. 체크 해제 시 이전 지원 선택을 복원합니다. 원래 공급가·배분 금액은 보존합니다.
결산은 고다 지원 비용 / 멤버 부담비용 / 객원 비용 / 다이빙솔루션 카드결제 비용 / 외부 지원금액으로 구분합니다. 앞의 네 지출 항목의 합이 부가세 포함 총 지출이며, 외부 지원금을 차감한 총비용을 별도로 표시합니다. 외부 지원금은 수입이므로 고다 지원비에 더하지 않습니다. 개인 지원금과 선결제는 개인 정산에서 별도 반영됩니다. 기존 멤버 리조트 총액의 개인 미배분 규칙은 유지됩니다.
기존 추가 프로젝트 지원금은 외부 지원금액으로 이어서 사용합니다. PNG에도 동일 분류를 적용합니다.

## v24 인원수로 나누기
비용 항목의 나눌 인원에 숫자를 입력하면 1인당 참고 금액을 표시합니다. 카드결제는 부가세 포함 금액을 사용합니다. 이름별 청구는 저장된 배분을 사용하며, 새 총액은 등록 인원을 기준으로 배분합니다.

## v25 화면 및 입력
전 화면과 PNG에 밝은 바탕과 주황색 포인트를 적용했습니다. 비용 입력에서 Enter를 누르면 총액 → 나눌 인원 → 다음 항목 총액 순서로 이동합니다.

## v27 다이빙 카드 계산
멤버 다이빙 총액을 입력하면 카드 부가세는 멤버 총액에만 적용합니다. 별도로 입력한 객원 다이빙 비용은 객원 정산에 반영합니다.

## v28 팀·숙박 배정과 렌탈
팀과 객실은 기본 5칸이며 ＋ 인원 버튼으로 한 칸씩 추가합니다. 팀·숙박 PNG는 배정된 인원만 담아 각각 한 장으로 저장합니다. 렌탈 입력과 집계에는 더블탱크만 표시합니다.
