# 고스트다이빙코리아 프로젝트 관리

index.html, app.js, logo.png를 같은 폴더에 두고 사용하세요. 로고는 사용자 제공 원본입니다.
기존 GitHub 저장소에서 세 파일을 교체하면 Vercel의 연결 설정에 따라 재배포됩니다.
새 배포: 저장소 최상위에 두 파일 업로드 → Vercel Import → Other → Build Command 비움 → Output Directory .

## 화면
- 다이빙현황표: 금·토·일 O/X, 32%, 더블탱크 렌탈, DPV, 촬영, 출발, 비고. 날짜별 인원 집계.
- 숙박 배정: 숙박 타입 및 금·토·일별 외부숙박/공동숙박/숙박 없음 선택. 이전 O 기록은 분류 전까지 숙박(분류 필요)로 표시.
- 팀 배정: 기존 참여자 명단에서 팀을 선택. 최대 5팀, 팀당 5명. 팀 이름과 비고 수정 가능.
- 정산: 기존 비용 + 식대 + 자유 명칭 비용 6칸. 비용 합계에서 지원액을 차감하고 기납부 금액과 대조합니다.

각 화면을 A3 가로 한 페이지 PDF 또는 4960×3508 JPG로 저장합니다.
PDF는 이미지 방식으로 텍스트 검색을 지원하지 않습니다.
비용 항목명은 표 머리글에서 수정할 수 있습니다. 자유 명칭 6칸은 비용에 더해집니다.

## 저장
서버 없이 같은 주소·기기·브라우저에 자동 저장됩니다. 이전 버전 자료도 자동으로 불러옵니다.
브라우저 데이터를 삭제하거나 시크릿 모드를 사용하면 자료가 사라질 수 있습니다.
새 프로젝트 시작 전 프로젝트 보관을 진행합니다. 입력 자료는 GitHub나 서버로 전송하지 않습니다.

## 연간 통계 및 백업
프로젝트명·시작일·종료일 입력 → 프로젝트 보관 → 연간 통계에서 연도 선택.
연도와 월은 프로젝트 시작일 기준입니다. 보관된 프로젝트만 집계하며, 보관 후 수정한 내용은 다시 보관해야 반영됩니다.
이름은 앞뒤 공백을 제외한 동일 문자열을 동일인으로 인식합니다. 동명이인은 강성모_1, 강성모_2처럼 구분하고 매번 같은 이름을 사용하세요.
개별 참여횟수는 참여한 프로젝트 수, 다이빙 참여횟수(일)는 O를 입력한 날짜 수입니다. 실제 잠수 횟수가 아닙니다.
남녀 비율은 중복 제외한 성별 확인 인원 기준입니다. 같은 이름에 남/여가 다르게 입력되면 성별 불일치로 표시합니다.
정산 항목명 아래의 분류를 기준으로 비용을 합산합니다. 항목명 변경 시 분류도 확인하세요. 지원비용은 단체지원 입력액의 합계입니다.
폐기물 종류는 직접 입력하고 수거량은 kg로 입력합니다. 종류를 같은 표기로 사용하면 연간 합산됩니다. 수거가 없으면 예: 수거없음 / 0kg로 기록할 수 있습니다.
프로젝트 보관함 → 전체 데이터 백업(JSON)을 별도 파일로 보관하세요. 백업 불러오기는 동일 프로젝트 번호를 병합해 중복 합산을 방지합니다.
연간 통계의 PPT용 통계 데이터(JSON)를 다운로드하면 월별·개별·비용·폐기물 통계를 PPT 제작에 사용할 수 있습니다. 이 버전은 PPT 파일 자체를 생성하지 않습니다.
연간 PDF/JPG는 현재 선택한 통계 화면 및 페이지를 출력합니다. 개별 참여·폐기물 종류는 24개씩 페이지를 나눕니다.
