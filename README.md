# 고스트다이빙코리아 프로젝트 관리

index.html과 app.js를 같은 폴더에 두고 사용하세요.
기존 GitHub 저장소에서 두 파일을 교체하면 Vercel의 연결 설정에 따라 재배포됩니다.
새 배포: 저장소 최상위에 두 파일 업로드 → Vercel Import → Other → Build Command 비움 → Output Directory .

## 화면
- 다이빙현황표: 금·토·일 O/X, 32%, 더블탱크 렌탈, DPV, 촬영, 출발, 비고. 날짜별 인원 집계.
- 숙박 배정: 숙박 타입 및 금·토·일별 외부숙박/공동숙박/숙박 없음 선택. 이전 O 기록은 분류 전까지 숙박(분류 필요)로 표시.
- 팀 배정: 기존 참여자 명단에서 팀을 선택. 최대 5팀, 팀당 5명. 팀 이름과 비고 수정 가능.
- 정산: 기존 비용 + 식대 + 자유 명칭 비용 6칸. 비용 합계에서 지원액을 차감하고 기납부 금액과 대조합니다.

각 화면을 A3 가로 한 페이지 PDF 또는 4960×3508 JPG로 저장합니다.
PDF는 이미지 방식으로 텍스트 검색을 지원하지 않습니다.
비용 항목명은 표 머리글에서 수정할 수 있습니다. 자유 명칭 6칸은 비용에 더해집니다.

## 저장
서버 없이 같은 주소·기기·브라우저에 자동 저장됩니다. 이전 버전 자료도 자동으로 불러옵니다.
브라우저 데이터를 삭제하거나 시크릿 모드를 사용하면 자료가 사라질 수 있습니다.
새 프로젝트 시작 전 최종 PDF/JPG를 보관하세요. 입력 자료는 GitHub나 서버로 전송하지 않습니다.
