# 고스트다이빙코리아 프로젝트 정산

## 실행
index.html과 app.js를 같은 폴더에 두고 index.html을 브라우저에서 여세요.
배포 후에는 같은 주소의 같은 브라우저에서 입력 내용이 자동 복원됩니다.

## GitHub → Vercel
1. 이 폴더의 index.html과 app.js를 GitHub 저장소 최상위에 업로드합니다.
2. Vercel에서 해당 저장소를 Import합니다.
3. Framework Preset은 Other, Build Command는 비워 두고 Output Directory는 . 으로 지정합니다.
4. Deploy 후 발급된 주소에서 작업합니다.

로그인·서버·외부 라이브러리·추적 스크립트가 없습니다. 입력한 개인정보는 GitHub 소스나 서버에 저장되지 않습니다.
브라우저 자동 저장 실패 시 화면에 경고가 표시됩니다. 파일 URL의 저장 동작은 브라우저마다 다를 수 있으므로 배포 주소 사용을 권장합니다.
PDF는 한 페이지 이미지 방식이며 텍스트 검색·편집은 지원하지 않습니다. JPG는 4960×3508 픽셀입니다.
최대 25명이며 세 날짜의 제목을 직접 수정할 수 있습니다. 긴 메모는 출력 시 자동 축소됩니다.
새 프로젝트를 누르면 확인 후 현재 작업을 초기화합니다. 초기화 전에 PDF/JPG를 보관하세요.

운영 현황·숙박 배정·정산을 각각 한 페이지 PDF/JPG로 저장합니다. 정산표 머리글에서 비용 항목명을 수정할 수 있습니다. 비용 4개 항목 합산 후 지원액을 차감하는 계산 방식은 유지됩니다. 이전 버전 브라우저 데이터는 최초 실행 시 자동으로 불러옵니다.
