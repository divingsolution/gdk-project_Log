# 고스트다이빙코리아 프로젝트 관리 · v20

기존 배포 폴더의 index.html, app.js를 교체하고 logo.png는 그대로 유지하세요.
같은 사이트 주소·기기·브라우저에서 기존 저장값을 이어서 사용합니다.

## 정산 화면
1. 발생 비용 입력: 기존 비용 항목·총액·배분 기준 유지. 11개 비용 항목을 한 줄에서 입력. 배분 설정과 개인별 상세표는 접어서 표시.
2. 개인 선결제: 기존 기납부 금액을 그대로 사용. 결제자별 선구매 내역 입력 추가.
3. 개인별 정산: 배정 비용 - 개인 지원금 - 선결제액. 기존 1,000원 단위 올림 유지. 양수는 추가 납부, 음수는 환급 예정.
4. 프로젝트 최종 요약: 총 발생 비용 - 프로젝트 지원금. 개인 지원금·선결제를 중복 차감하지 않음.

멤버 리조트 총액은 개인에게 자동 배분하지 않습니다. 선결제한 구매비는 발생 비용에 한 번 포함해야 합니다. 선구매 내역은 설명이며 별도 비용을 자동 추가하지 않습니다.
프로젝트 지원금은 전체 요약에만 적용되며 멤버/객원 대상 정산서에 임의 배분하지 않습니다.
PDF 저장 버튼을 제거했습니다. 기존 PNG 저장은 유지합니다.
현재 작업·보관함·JSON 백업에 새 입력값도 저장됩니다. 기존 연간 통계의 지원비 집계는 개인 지원금 기준을 유지합니다.
배포 전 기존 사이트의 프로젝트 보관함에서 전체 데이터 백업(JSON)을 보관하세요.
